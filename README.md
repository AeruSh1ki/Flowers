# Flowers

A small interactive flower surprise: open the envelope to grow a floating golden-angle garden, let it fill the screen and fade after a three-second pause, click to reveal the bouquet, then click to open the letter.

The provided music loops from the first envelope click, which also starts the flower animation. Browsers require a user gesture before they allow audio playback.

## Run locally

Open `index.html` in a browser. The page is static and has no build step.

## Customize the letter

Edit the text in the `.letter-copy` and `.signoff` elements in `index.html`.
